Задачки взяты из https://coderun.yandex.ru/catalog

## Структура

Каждая задача `N` лежит в своей папке:
```
tasks/N/solution.py
tasks/N/tests/config.json
tasks/N/tests/1_in.txt
tasks/N/tests/1_out.txt
tasks/N/tests/2_in.txt
tasks/N/tests/2_out.txt
...
```

`tests/config.json` задаёт лимиты задачи (как на coderun):
```json
{
  "time_limit_s": 1,
  "memory_limit_mb": 256
}
```
Если файла нет, используются значения по умолчанию (5 с / 256 МБ).

## Тесты

Прогнать тест вручную: (подаем данные на вход и проверяем вывод):
```shell
python3 tasks/3/solution.py < tasks/3/tests/1_in.txt | diff - tasks/3/tests/1_out.txt && echo "MATCH"
```

Прогнать все тесты всех задач:
```shell
python3 run_tests.py
```

Прогнать все тесты конкретной задачи (можно перечислить несколько):
```shell
python3 run_tests.py 3
python3 run_tests.py 1 3
```

Раннер можно использовать и из кода:
```python
from run_tests import run_task_tests, run_all

run_task_tests(3)  # все тесты задачи 3
run_all()           # все тесты всех задач
```

Скрипт завершается с кодом `0`, если все тесты прошли, и `1` — если хотя бы один упал.

Раннер запускает решение с лимитами из `tests/config.json`. Лимит времени проверяется самим раннером
(опрос процесса + `kill` по истечении `time_limit_s`). Лимит памяти enforce-ится через **cgroup v2**
(`memory.max` на отдельную группу для каждого теста) — это ограничивает суммарную память решения
**и всех его подпроцессов вместе**, а не только одного процесса. Если решение превышает лимит, вся
группа процессов убивается ядром целиком (OOM-killer), в том числе при превышении лимита времени
(`cgroup.kill`, чтобы не оставались висящие подпроцессы). Если cgroup v2 недоступна (не Linux, нет
делегирования), раннер откатывается на `RLIMIT_AS` — но тогда лимит проверяется только для одного
процесса, подпроцессы решения он не учитывает. Превышение любого из лимитов засчитывается как провал теста.

Для каждого теста выводится фактическое время выполнения и пиковая память (`memory.peak` группы, либо,
при откате на `RLIMIT_AS`, пиковый RSS одного процесса):
```
Задача 3, тест 1: OK (0.02 с, 10.3 МБ)
```
